Это банковское приложение на основе архитектуры CQRS и Event Sourcing. Система состоит из сервисов c-service (командный сервис) и event-handler (сервис обработки событий). Для хранения данных используются базы данных PostgreSQL. Захват изменений из базы данных выполнен с помощью Debezium CDC, а доставка событий между сервисами осуществляется через брокер сообщений Apache Kafka. Для защиты эндпоинтов и аутентификации применяется Spring Security с JWT токенами. Для сборки и запуска выполните docker compose up -d --build из каталога проекта; c-service доступен на порту 5555, а PostgreSQL — на порту 5437.
